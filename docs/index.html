Chưa nạp data

Đưa mã vạch vào khung, cách 15–25 cm, máy tự bắt. Bắn lại cùng mã thì đưa ra khỏi khung rồi đưa vào lại.

Lần bắn gần nhất
Chưa có lượt nào. Bật camera hoặc bắn bằng súng/nhập tay ở ô trên.

Cách dùng với file kiểm kê

  1. Nạp data: chọn file Excel kiểm kê (có sheet "Phụ kiện" và "Máy"). Tool báo đúng/dư ngay lúc quét.
  2. Quét bằng camera, súng bắn Bluetooth/USB, hoặc nhập tay.
  3. Xuất Excel, mở file xuất, copy cột A (từ dòng 2) và dán vào ô A5 của sheet "Kiểm kê". Sheet "Kết quả" tự tính thiếu/dư.

Nhập danh sách sẽ cộng thêm vào phiên đang làm. Nhận file xuất từ tool này, file kiểm kê (lấy cột A sheet "Kiểm kê"), hoặc file có mã ở cột đầu tiên.
